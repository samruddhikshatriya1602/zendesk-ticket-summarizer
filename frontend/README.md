# Frontend

React + TypeScript + Vite client for the [Ticket Summarizer](../README.md).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173 (backend must be running on port 3001).

## Configuration

Optional `frontend/.env`:

```env
VITE_API_BASE_URL=http://localhost:3001
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm test` | Jest + React Testing Library |
